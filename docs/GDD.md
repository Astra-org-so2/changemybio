# Brainrot Factory: Tap & Collect — Game Design Document (MVP v0.1)

> Философия: **сначала доказать core loop, потом масштабировать.**
> Всё, что не улучшает retention / session time / monetization — не входит в MVP.

## 1. Концепция

Мемный tap/idle-коллекционер. Игрок управляет «Фабрикой брейнрота», которая производит абсурдных оригинальных существ. Тап = валюта, валюта = улучшения и сундуки, сундуки = персонажи, персонажи = множители, множители = prestige, prestige = новый более быстрый круг.

**Жанр:** Clicker / Idle / Collection / Meme.
**Платформа:** Яндекс Игры, mobile-first (portrait), desktop-адаптация.
**Сессия:** 3–10 минут, 2–4 раза в день.
**Аудитория:** 10–25 лет, RU-регион в первую очередь (RU/EN локализация из коробки).

## 2. Core Loop

```
ТАП → Coins → Сила тапа ↑ / Авто ↑ → Basic Chest (coins) → Персонаж (множитель + пассив)
   → доход ↑ → runEarned ≥ порог → PRESTIGE → Prestige Points (×0.25 каждый) → новая зона → цикл
```

| Цикл | Длительность | Награда |
|---|---|---|
| Микро | 10–40 с | следующий апгрейд (кнопка загорается зелёным) |
| Мезо | 1–4 мин | следующий Basic Chest (цена ×1.6 за открытие, сброс при prestige) |
| Макро | ~25–35 мин активной игры | первый prestige (симуляция: `node tools/sweep.mjs v`) |
| Мета | дни–недели | коллекция 63 персонажа, бонусы 25/50/75/100 %, зоны prestige |

## 3. Первые 5 минут (по симуляции с 3 тапа/сек)

| Время | Событие | Реализация |
|---|---|---|
| 0–1 с | Игрок видит персонажа (Сигма-Огурец) и подсказку «Нажми на персонажа!» | стартовый персонаж выдаётся всегда; loader < 100 мс логики |
| 1–5 с | Первый тап, +1, партиклы, звук, число летит вверх | pointerdown, без задержки |
| ~10 с | Первое улучшение (10 монет = 7–10 тапов), подсказка «Улучши силу тапа ↓» | кнопка становится зелёной при доступности |
| ~20 с | Первый авто-доход (25 монет) — цифра ⚙️/сек появляется | |
| ~50 с | Первый сундук (100 монет) — pulse на кнопке «Сундуки» | подсказка после 2 улучшений |
| 1–2 мин | Первый редкий (17 % за сундук + pity на 10-м); 6 персонажей к 2 мин | |
| 2–3 мин | Открыт первый milestone (25 уровень → ×2) | |
| 3–5 мин | Первое ежедневное задание выполняется (500 тапов), даёт гемы → видна цель «Редкий сундук за 50 💎» | |

К концу первой сессии игрок понимает: тап → монеты → апгрейд → сундук → персонаж → prestige → возвращайся за offline-доходом и Day 2.

## 4. Системы

### 4.1 Валюты
- **Coins** — основная, из тапов/авто/offline/daily. Сбрасывается при prestige.
- **Gems** — из дублей, квестов, daily, IAP. Не сбрасывается. Тратится на Rare/Epic/Legendary сундуки.
- **Prestige Points** — из prestige. Постоянный множитель ×(1 + 0.25·PP).

### 4.2 Формулы (см. `src/game/Economy.js`, параметры — `src/config/balance.js`)
```
tapBase(level)    = (tapBase + level·tapPerLevel) · 2^floor(level/25)
coinsPerTap       = (tapBase · charTapMult · charIncomeMult + 0.1·cps) · prestigeMult · collectionMult · boost · AB.tap_mult
autoBase(level)   = incomeBase · level · incomeGrowth^level · 2^floor(level/25)
coinsPerSecond    = (autoBase + Σ passiveIncome) · charIncomeMult · prestigeMult · collectionMult · boost
upgradeCost       = base · growth^level          (tap: 10·1.13^n, auto: 25·1.14^n)
charBonus(lvl)    = 1 + 0.25·(lvl-1)             (дубли повышают уровень до 10)
charIncomeMult    = 1 + Σ (baseMultiplier_i − 1)·charBonus_i      (аддитивно — без взрывного роста)
prestigePoints    = floor(√(runEarned / 2e7)),  доступно при runEarned ≥ 2e7
offline           = cps · min(Δt, 8ч) · 0.6,  ×2 за rewarded
```

### 4.3 Персонажи — 100 (47/25/16/8/4) + 1 event
Оригинальные, юмор в названиях и описаниях («Капибара-Бухгалтер», «Кот-Юрист 3000», «Дед Wi-Fi»). Каждый: `id, name, rarity, baseMultiplier, passiveIncome, tapMultiplier, unlockCondition, asset, description`. Визуал MVP: emoji-плейсхолдер + процедурная подсветка по редкости; поле `asset` готово для WebP (Phase 4).

### 4.4 Сундуки и pity (честно показаны в UI)
| Сундук | Валюта | Цена | Common/Rare/Epic/Leg/Myth | Pity |
|---|---|---|---|---|
| Basic | coins | 100 ×1.6ⁿ | 80/17/2.5/0.45/0.05 | Rare+ на 10-м |
| Rare | gems | 50 | 40/45/12/2.5/0.5 | Epic+ на 15-м |
| Epic | gems | 150 | 0/55/35/8.5/1.5 | Legendary+ на 20-м |
| Legendary | gems | 400 | 0/0/60/34/6 | Mythic на 25-м |

Дубли → +уровень персонажа (+25 % его бонуса) + гемы. Ничего не пропадает. 60 % bias к ещё не полученным в пуле редкости.

### 4.5 Collection bonus
25 % → +10 %, 50 % → +25 %, 75 % → +50 %, 100 % → +100 % к доходу. Долгосрочная цель, показывается прогресс-баром.

### 4.5a Трек «Удача» (после 1-го prestige)
Третий апгрейд за монеты: +0.5 % шанса крита за уровень, cap 30 уровней (5 % → 20 %). Не сбрасывается prestige — это мета-награда за первый перезапуск и новая цель для монет на поздней стадии.

### 4.6 Prestige («Перезапуск фабрики»)
Сбрасывает: coins, апгрейды, цену Basic chest. Сохраняет: персонажей, гемы, PP, покупки. Экран показывает «x1.0 → x1.5» до подтверждения. Зоны с уникальными бонусами: Гараж → Подвал (1: офлайн 70 %) → Фабрика (3: офлайн 80 %, авто ×1.25) → Лаборатория (6: офлайн 90 %, авто ×1.5, крит ×1.5) → Космос (10: офлайн 100 % и до 12 ч, авто ×2, крит ×2). Бонусы показаны на экране prestige — игрок видит, ради чего следующий цикл.

### 4.7 Daily / Quests
7-дневный календарь с растущими наградами (монеты = N минут текущего cps, гемы 5→100, сундуки на Day 3/5/7). Пропуск дня сбрасывает streak. 3 квеста/день из пула 7; квест «посмотри видео» — опциональный, не блокирует остальные.

### 4.8 Combo / Crit
Combo растёт при интервале < 900 мс: x1.2 (10), x1.5 (25), x2 (50), x3 (100); падает плавно. Крит 5 % ×5, супер-крит 0.5 % ×25; Lucky boost ×3 к шансу.

### 4.9 Offline
«Пока тебя не было…» — показывается сразу после загрузки, до геймплея. Кнопки: «Забрать» / «Забрать x2 📺». Нет рекламы без клика.

## 5. Juice
Scale-анимация тап-кнопки, canvas-партиклы (пул 220, авто-даунгрейд при FPS < 40), floating numbers, screen shake на критах, процедурные WebAudio-звуки (0 байт ассетов), glow по редкости, конфетти на Epic+ и prestige.

## 6. Что сознательно НЕ вошло в MVP
Leaderboard-экран (менеджер есть), временные события (архитектурный хук `unlockCondition.type='event'`), музыка, PNG-арт, серверная валидация покупок. Всё — Phase 2+ по `GROWTH_PLAN.md`.

## 7. Предположения (явно)
- [ASSUMPTION] Цены IAP в YAN (портальная валюта) — реальные цены задаются в Консоли; в коде только `fallbackPriceYan` для мока.
- [ASSUMPTION] Время до первого prestige 25–35 мин активной игры — оптимально для D1; будет проверено на реальных данных (`prestige` event).
- [ASSUMPTION] Emoji-плейсхолдеры допустимы для soft-launch; для CTR карточки нужен кастомный арт (см. `STORE_ASSETS.md`).

## Достижения (v0.8)
14 ступенчатых достижений в 5 категориях (`src/config/achievements.js`): тапы, монеты, коллекция, сундуки, престиж. Постоянные (не сбрасываются prestige), награда — гемы, начисляется автоматически с тостом. Суммарно ≈ 3 000 💎 за полное закрытие — это «бесплатный» источник премиум-валюты, снижающий ощущение paywall и дающий длинные цели для D30+. Вкладка внутри экрана «Коллекция» (без новой кнопки в нижнем меню). Аналитика: `achievement_unlock {id, tier, target, gems}`.
