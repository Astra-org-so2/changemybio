# STORE_ASSETS

## Требования Яндекс Игр (проверить в Консоли перед загрузкой — размеры могут обновляться)
- **Иконка:** квадрат 512×512 PNG/JPG, без прозрачности, без текста/логотипов сторонних брендов, без скруглений (платформа скругляет сама).
- **Обложка (cover):** 800×470 (горизонтальная), персонаж занимает ≥ 50 % площади, контраст, читаемо в миниатюре.
- **Скриншоты:** минимум 3, портретные для мобайла (например 1080×1920) и/или десктоп. Реальный геймплей, без UI-мокапов.
- **Промо-видео:** опционально, 15–30 с, первые 3 с — тап и реакция.

## 5 концепций иконки
1. **«Огурец в шоке»** — Сигма-Огурец крупным планом, широко раскрытые глаза, жёлтый фон, монета отражается в глазах.
2. **«Мифический глитч»** — силуэт Абсолютного Брейнрота в красно-фиолетовом свечении, знак «?» — интрига редкости.
3. **«Капибара с калькулятором»** — Капибара-Бухгалтер, довольное лицо, монеты летят, зелёный фон.
4. **«Палец + взрыв»** — гигантский палец тапает по персонажу, вокруг «+999», оранжевый фон (жанровое считывание «кликер»).
5. **«Коробка приоткрыта»** — сундук, из щели бьёт свет и виден глаз персонажа; фиолетовый фон.

## 5 концепций thumbnail/обложки
1. Три персонажа разной редкости (серый/синий/золотой) в ряд + «Собери всех!».
2. Огурец на фоне заводского цеха с трубами, из труб вылетают мемные существа.
3. «До/После prestige»: слева унылый гараж, справа космос, стрелка.
4. Момент дропа: сундук взорвался, Легендарный выпал, «0.45 %!» крупно.
5. Персонаж смотрит на игрока с надписью «Тапни меня» и стрелкой на палец.

## Правила
- Только оригинальные персонажи и стилистика (никаких отсылок к чужим франшизам/брендам).
- Иконка: одна эмоция, один персонаж, без мелких деталей, читаема в 64×64.
- A/B: `AB_CONFIG.game_title_variant` логируется в аналитике — сопоставлять с CTR-тестами витрины.
