## 4. Remote Config (Консоль → Флаги)

Дефолты зашиты в `src/config/ab.js`; в Консоли создавать флаги **с теми же именами**, значения — строки.

Обязательные для запуска (можно оставить дефолт, но флаг должен существовать, чтобы менять без релиза):

| Флаг | Дефолт | Зачем |
|---|---|---|
| `min_interstitial_interval_sec` | 180 | Пауза между interstitial |
| `max_interstitial_per_session` | 4 | Потолок за сессию |
| `min_session_time_before_ad_sec` | 120 | Никакой рекламы в первые 2 минуты |
| `payments_server_url` | `''` | URL сервера проверки подписи (пусто = клиентская проверка) |
| `event_override` | `''` | Принудительный запуск/остановка события |

Для A/B (создать эксперименты после первых 1000 DAU, см. GROWTH_PLAN):
`tap_mult`, `upgrade_cost_mult`, `chest_cost_mult`, `free_chest_cooldown_sec`, `rewarded_reward_mult`, `income_boost_duration_sec`, `starter_pack_trigger`, `starter_pack_offer_cooldown_sessions`, `remove_ads_offer_after_int`, `remove_ads_offer_cooldown_sessions`, `shortcut_prompt_after_sec`, `shortcut_reward_gems`, `onboarding_variant`, `game_title_variant`.

- [ ] Все 19 флагов созданы с дефолтами из `ab.js`
- [ ] Ни один флаг не понижает `min_session_time_before_ad_sec` ниже 60 — иначе риск отказа модерации

## 7. Модерация

Пройти `docs/YANDEX_MODERATION_CHECKLIST.md` полностью (все пункты ✅). Ключевые причины отказов, которые закрыты кодом:

- реклама до начала игры — нет (`min_session_time_before_ad_sec`)
- реклама без паузы геймплея — `GameplayAPI.stop()` перед показом
- принудительный rewarded — нет, все награды опциональны
- невыполненный `LoadingAPI.ready()` — вызывается после первого кадра
- чужие IP — 100 % оригинальный арт/имена/звуки

- [ ] Отправить на модерацию
- [ ] Ответ обычно 1–3 рабочих дня; при отказе — цитата пункта правил → правка → повторная отправка (без смены версии, если только ассеты)
